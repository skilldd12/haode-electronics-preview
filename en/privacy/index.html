Privacy policy

Last updated 2026-10-27

What we collect

When you submit an enquiry we store the name, company, email, telephone, country or region, requirement text, part numbers and quantities you provide, plus any attachment you upload.

The server also records the submission time and referring page for diagnosing abnormal submissions. IP addresses are stored only as a hash.

Why we collect it

The information is used to answer the enquiry, verify part numbers and continue order communication. It is not used for marketing unrelated to the request.

How attachments are handled

Attachments are stored in the application data directory and are never exposed through a public static path. Only authorised staff handling that enquiry can open them. Files are never executed or shared publicly.

Retention

Enquiry records and attachments are kept for 24 months by default for after-sales traceability, then deleted or anonymised. You may request earlier deletion at any time.

Cookies

Public pages use only what is needed for session and language preference. The admin area uses a single session cookie to keep you signed in. No third-party advertising or analytics scripts are loaded.

Your rights

You may ask to view, correct or delete the enquiry information we hold. Use the contact page and quote the reference number so we can match the record.
